# Harika's Kitchen — Privacy Policy (GitHub Pages)

This repository contains a static privacy-policy page for the Harika's Kitchen WhatsApp ordering project.

## Important: complete the policy before publishing

The current policy is a **draft template**, not legal advice. Do not submit it to Meta or publish it as final until the business owner confirms that it accurately describes the real service and completes every square-bracket placeholder in `index.html`.

Required confirmations include:
- Correct business/legal name and privacy contact email.
- Appropriate business contact/postal details.
- Actual data collected by WhatsApp, Supabase and any other providers.
- Retention periods for orders, messages, webhook logs and customer records.
- Actual sharing, international transfer and security practices.

The business owner should review the policy and obtain professional advice if needed. The developer should not invent the client's legal identity or claim practices that have not been implemented.

## Publish using GitHub Pages

1. Upload the files in this folder to the root of the already-created GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish. The public URL usually follows `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.
6. Open the URL in a private/incognito browser window and confirm it loads without signing in.
7. Enter the exact public URL in Meta App Settings → Basic → Privacy Policy URL.

If your repository uses a different default branch, select that branch instead.
